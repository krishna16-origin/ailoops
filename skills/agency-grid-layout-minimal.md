MINIMAL AGENCY GRID SKILL — a design-direction to apply across the whole page when the site should read like a refined architecture/design/strategy studio: disciplined grid, oversized typography, quiet structural detail. Not a generic startup landing page, not a card-heavy dashboard.

Visual target: build on a strict multi-column grid with large open spans and generous negative space; oversized headlines with tight tracking are the primary visual anchor, paired with small uppercase utility labels (section markers, metadata) in adjacent columns; keep surfaces minimal — light neutral backgrounds, thin separators, quiet image frames, very restrained accent color; imagery should feel architectural/premium (large panoramic blocks), not card-gallery-style.

Implementation: wide max-width shell with clear column divisions; confident type-scale contrast (very large display sizes next to tiny uppercase metadata and calm body copy); understated buttons (thin gradient-border wrappers — see the gradient-border skill — over loud filled pills); only light structural motion (masked text reveals, slow image settle, restrained hover shifts); any background effect should stay extremely quiet (faint wireframe, low-opacity geometry).

Avoid: repeated interchangeable cards, heavy borders/big shadows/dense nesting that fight the grid, overusing accent color, filling every gap instead of preserving intentional whitespace.
